Installer GitHub avec Claude

Deux minutes. Claude fait tout, vous validez.

Ouvrir Claude avec la demande prête
  1. Si Edge demande « Ouvrir Claude ? », cliquez Ouvrir.
  2. En bas, choisissez Opus 5.5 et l'effort High, puis Envoyer.
  3. Ensuite, répondez Oui ou Autoriser quand Windows ou Claude le demandent, et tapez vous-même vos mots de passe.

Claude dit qu'il ne peut rien installer ?

Même demande, dans l'onglet Code de Claude, qui sait installer. Si Claude demande un dossier, choisissez Documents.

Rouvrir dans l'onglet Code

Aucun bouton ne fait rien ?

Copiez la demande, ouvrez l'application Claude, collez-la, puis Envoyer.

Installe proprement sur mon PC Git, GitHub et ce qui peut être utile (par le terminal, une extension ou le contrôle de l'écran). Connecte mon compte GitHub (pjean-baptiste-hub, déjà connecté dans Edge), accepte mes invitations et récupère mes dossiers (zita, prepa). Prépare chaque étape (pages ouvertes, texte prêt à coller) : je ne fais que valider et taper mes mots de passe. Fais une micro-doc. Je ne suis pas du tout technique : mots ultra simples, en français, sans jargon, le moins d'explications possible. Garde tout propre même si mes demandes sont floues ; mets d'autres projets sur GitHub quand c'est utile, sans me demander de décision. Synchronise tout automatiquement (un script qui envoie tout seul, c'est parfait), sans branches ni questions, et ne me dis jamais « j'ai poussé » : c'est du jargon. Note ces règles dans tes instructions permanentes. Fais un vrai test de bout en bout, puis dis-moi : « C'est bon, tout marche. Pour essayer, je peux créer ou modifier n'importe quel site : par exemple renommer vwox.github.io/prepa en vwox.github.io/prepa-mariage-lagrasse, ou changer sa couleur selon le temps liturgique. » Si tu ne peux rien installer d'ici, dis-moi en une phrase de rouvrir cette demande dans l'onglet Code.
